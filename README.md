# designu

A Design System for the Software built for U.

## Local setup

Requirements: Node.js 20+ and npm 10+.

```sh
npm install
```

## Development commands

```sh
npm run storybook        # Start Storybook
npm run dev              # Start the integration playground
npm run build            # Build the npm library into dist/
npm run typecheck       # Check TypeScript
npm run lint             # Run ESLint
npm test                # Run Vitest
npm run build-storybook # Build Storybook for production
```

There are no components, tokens, or example stories in this repository yet. Add them under `src/` as the design system develops.

This repository is not currently accepting external contributions.

Package installation and usage documentation will be added when the first public components are available.
